🧭 This Python + OpenGL project transforms 2D map images into a beautifully lit, interactive 3D globe 🪐. Rotate Earth with WASD keys, toggle between maps 🗺️ using V, and generate dynamic projections with C! 🔁

🎨 Features:

Equirectangular map projection on a sphere 🟠

Real-time lighting & sun simulation ☀️

Tissot’s Indicatrix distortion maps support 🧠

Interactive globe rotation 🎮

Plays background music 🎶 with sound.mp3

🛠️ Built with:
PyOpenGL, PIL, Pygame, math, and GLUT
